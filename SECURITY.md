# Security policy

The repository is experimental and has no supported production release. The example keeps physics on the server and accepts only authorized, bounded driver input; it is not a complete anti-cheat system.

Report vulnerabilities using GitHub's private vulnerability reporting when enabled on this repository. Do not place credentials, private experience data, or a working abuse payload in a public issue. For ordinary physics defects, use the physics bug template.

Never commit Roblox API keys, GitHub tokens, cookies, `.env` files, or local tool credentials. No Open Cloud publishing credentials are needed for the local development workflow.
