# Third-party provenance

The initial implementation was written for this repository from mathematical definitions and an original technical synthesis. No simulator implementation, source archive, tire coefficient file, restricted dataset, or paid standard is vendored.

| Material | Treatment |
| --- | --- |
| User-supplied Roblox vehicle research ZIP | Preserved under ignored `.local/research`; file-level SHA-256 catalog published as metadata |
| User-supplied consolidated guide and master manual | Preserved locally; operational recommendations evaluated as source material |
| Roblox documentation | Referenced through direct links; units and API contracts rechecked for initial setup |
| Luau LSP Roblox definitions | Downloaded from pinned upstream version 1.70.1 into ignored local storage and checksum verified; upstream terms apply |
| Rokit, Rojo, StyLua, Selene, Lune, Wally, Luau LSP, GitHub CLI | Installed external tools, not project runtime dependencies; upstream licenses apply |
| Serena 2.1.0, uv 0.13.6, managed Python 3.13.18 | External agent tooling; Serena is GPL-3.0-or-later and is not linked into or redistributed with the MIT vehicle library |
| Official Roblox Studio agent plugin and Serena source checkouts | Ignored local research references, pinned in `config/agent-tools.json`; upstream licenses remain authoritative |
| CommonRoad, Chrono, PhysX, Jolt, VDrift, A-Chassis, FASTSim and research datasets | Research leads only; no code/data imported into the public library |

The supplied knowledge-base archive has no identified top-level distribution license. Preserving it locally maintains provenance without assigning it this project's MIT license. Review original terms and required attribution before publishing any future source excerpt, model parameter set, or dataset-derived calibration.

`docs/research/catalog.json` establishes file identity. It does not prove the correctness, license, authorship, or empirical validity of an imported claim.
